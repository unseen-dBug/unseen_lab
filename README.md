# unseen_lab# // unseen-radar

> *"Every system has a blind spot. I'm just looking where no one else does."*

Painel web local desenvolvido por **unseen-dBug** para mapeamento de dispositivos conectados na rede Wi-Fi (IP + Endereço MAC) em tempo real, com interface estilo terminal.

### Como rodar
1. Tenha o **Python 3** instalado no PC ou no Termux (Android).
2. Baixe o arquivo `radar.py` e execute no terminal:
   ```bash
   python radar.py
   ```
3. Abra o navegador e acesse: `http://127.0.0.1:8080`

---
*Uso estritamente educacional e para auditoria da própria rede doméstica.*
